Implement GDPR Compliance Features and Zero-Knowledge Selective Disclosure

Closes #111
Closes #113

## Description

This PR implements two major privacy enhancements to the SDK:

### 1. GDPR Compliance Features (#113)
Added a new `GDPREngine` (accessible via `sdk.gdpr`) which provides:
- **Right to Erasure (Soft Delete)**: `processErasureRequest` revokes all credentials associated with a DID with an "Erasure Request" reason.
- **Data Portability**: `exportDataPortability` gathers all known credentials, DID documents, processing records, and consents into a structured JSON string.
- **Consent Management**: `recordConsent`, `revokeConsent`, and `hasValidConsent` methods to track and enforce data processing consent.
- **Data Processing Logs**: `logDataProcessing` and `getExpiredRecords` to comply with Article 30 and data retention policies.
- **Right to Rectification**: `processRectification` to revoke outdated credentials for updates.

### 2. Zero-Knowledge Selective Disclosure (#111)
Extended the `ZKProofsClient` with:
- **Selective Disclosure Proof Generation**: `createSelectiveDisclosureProof` allows holders to select specific attributes to reveal while hiding the rest of the credential using ZK-SNARKs.
- **Selective Disclosure Verification**: `verifySelectiveDisclosureProof` verifies the proof on-chain against the specified expected attributes.

## Changes
- Created `sdk/src/gdpr.ts` and exported `GDPREngine` and types in `sdk/src/index.ts`
- Added `createSelectiveDisclosureProof` and `verifySelectiveDisclosureProof` to `sdk/src/zkProofs.ts`
- Initialized `GDPREngine` inside the main `StellarIdentitySDK` constructor
